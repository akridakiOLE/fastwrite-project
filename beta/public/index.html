First-time setup — 4 steps

Download & install

  1. Click Download FastWrite for Windows above — you'll get a .zip file.
  2. Right-click the .zip → Extract All…, then open the extracted FastWrite folder and double-click FastWrite.exe. Run it from the extracted folder — not from inside the zip.
  3. If Windows shows a blue "Windows protected your PC" screen, click More info → Run anyway. This appears only because the app is not yet code-signed; it is safe to run.

Create your FastWrite account

  1. On first launch, click Register on the login screen.
  2. Pick a username & password — the account is stored only on your computer.
You get a free trial of 10000 documents — no license key needed.

Add your Gemini API key (BYOK)

  1. Go to Google AI Studio and sign in.
  2. Click Get API key → Create API key and copy it.
  3. In FastWrite open Settings, paste the key into the Gemini API key field, and Save.
You bring your own key (BYOK) and pay Google directly for AI usage. The key is stored encrypted on your computer.

Connect your Xero account

  1. You need an existing Xero account. No account? Create a free account / trial / demo company at xero.com first.
  2. In FastWrite Settings, click Connect to Xero.
  3. Log in on Xero and choose the organisation to connect.
  4. Review and authorize the requested permissions.
  5. You're returned to FastWrite, now connected. Disconnect anytime from Settings.
Connect to Xero uses secure OAuth 2.0. It does not create a Xero account — it links FastWrite to your existing organisation. No secret keys are stored in the app.

Πρώτη ρύθμιση — 4 βήματα

Κατέβασε & εγκατέστησε

  1. Πάτα Download FastWrite for Windows πιο πάνω — θα κατέβει ένα αρχείο .zip.
  2. Δεξί κλικ στο .zip → Extract All… (Εξαγωγή όλων), μετά άνοιξε τον φάκελο FastWrite που βγήκε και κάνε διπλό κλικ στο FastWrite.exe. Τρέξ' το από τον εξαγμένο φάκελο — όχι μέσα από το zip.
  3. Αν εμφανιστεί μπλε παράθυρο «Windows protected your PC», πάτα More info → Run anyway. Εμφανίζεται μόνο επειδή η εφαρμογή δεν είναι ακόμα code-signed· είναι ασφαλές να την τρέξεις.

Φτιάξε λογαριασμό FastWrite

  1. Στο πρώτο άνοιγμα, πάτα Εγγραφή στην οθόνη login.
  2. Διάλεξε username & password — ο λογαριασμός μένει μόνο στον υπολογιστή σου.
Παίρνεις δωρεάν trial 10000 εγγράφων — χωρίς κλειδί άδειας.

Βάλε το δικό σου Gemini API key (BYOK)

  1. Πήγαινε στο Google AI Studio και κάνε login.
  2. Πάτα Get API key → Create API key και αντίγραψέ το.
  3. Στο FastWrite άνοιξε τις Ρυθμίσεις, επικόλλησε το key στο πεδίο Gemini API key και Αποθήκευση.
Φέρνεις το δικό σου key (BYOK) και πληρώνεις εσύ τη Google για τη χρήση του AI. Το key αποθηκεύεται κρυπτογραφημένο στον υπολογιστή σου.

Σύνδεσε τον λογαριασμό σου στο Xero

  1. Χρειάζεσαι υπάρχοντα λογαριασμό Xero. Δεν έχεις; Φτιάξε δωρεάν λογαριασμό / trial / demo company στο xero.com πρώτα.
  2. Στις Ρυθμίσεις του FastWrite, πάτα Connect to Xero.
  3. Κάνε login στο Xero και διάλεξε το organisation που θες να συνδέσεις.
  4. Έλεγξε και εξουσιοδότησε τα δικαιώματα που ζητούνται.
  5. Επιστρέφεις στο FastWrite, πλέον συνδεδεμένος. Disconnect όποτε θες από τις Ρυθμίσεις.
Το Connect to Xero χρησιμοποιεί ασφαλές OAuth 2.0. Δεν δημιουργεί λογαριασμό Xero — συνδέει το FastWrite με το δικό σου υπάρχον organisation. Κανένα μυστικό κλειδί δεν αποθηκεύεται στην εφαρμογή.
