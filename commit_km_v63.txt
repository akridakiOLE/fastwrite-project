Stavros, 16/9 with a screenshot from the phone: "every time a new question
opens, the previous one must close". Two open answers push the second one off
a phone screen, so tapping it looks like nothing happened.

renderFaq now attaches a toggle listener to each <details>; when one opens, the
others close. Two things worth writing down:
- the `toggle` event does NOT bubble, so a single listener on #faq-body would
  never fire. It goes on each element.
- the browser-native exclusive accordion (name="" on <details>) is deliberately
  NOT used: it is recent and not every phone that will run this app has it.
Closing the open one still leaves everything closed - it is an accordion, not a
radio group.
